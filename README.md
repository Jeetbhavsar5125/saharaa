# Saharaa 🌍✨

Saharaa is an Android accessibility application designed to assist visually impaired and blind users through voice assistance and smart accessibility features.

The goal of this project is to make smartphone usage easier, faster, and more independent for users who face visual challenges.

---

## 📱 Features

- 🎤 Voice Assisted Navigation
- 🔊 Text-to-Speech Support
- 🗣️ Voice Command Interaction
- 📞 Easy Calling Support
- 📍 Accessibility Focused UI
- 🚨 Emergency Assistance Features
- 🌐 Future AI-based Assistance Integration

## 🚀 Project Goal

Saharaa aims to bridge the accessibility gap by providing a user-friendly and voice-driven Android application for blind and visually impaired individuals.

The project focuses on:
- Accessibility
- Simplicity
- Voice-first interaction
- Real-world usability
